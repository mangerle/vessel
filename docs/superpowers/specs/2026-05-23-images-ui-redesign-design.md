# 镜像页面 UI 重构设计规格

## 1. 目标
重构 Docker 镜像管理页面，优化镜像拉取（Pull）流程，提升用户体验。

- **消除弹窗**：取消拉取镜像时的确认弹窗，改为直接执行或内嵌展示。
- **集成功能**：将镜像搜索与拉取功能完全内嵌在右侧详情区的“镜像仓库”选项卡中。
- **调整结构**：确保“镜像仓库”选项卡位于“层级结构”之前，作为默认或首选视图。
- **修复损坏**：修复 `src/views/Images.vue` 中存在的代码损坏和标签缺失问题。

## 2. 用户交互变更
### 2.1 镜像拉取流程
- **当前**：点击搜索建议 -> 弹出 `NModal` 确认 -> 点击确认 -> 执行拉取。
- **重构后**：
  - 用户在“镜像仓库”选项卡中进行搜索。
  - 点击搜索结果或在 `n-auto-complete` 中选中后，立即开始异步拉取，并显示后台任务进度。
  - 不再弹出任何确认对话框（除非发生严重错误）。

### 2.2 选项卡顺序
- **当前**：`pull` (镜像仓库) -> `layers` (层级结构) -> `inspect` (镜像详情)。
- **确认**：保持此顺序（“镜像仓库”已在最前），确保在未选中任何镜像时默认显示“镜像仓库”。

## 3. 技术架构
### 3.1 状态管理
- 使用 `imageStore` 处理搜索、拉取和列表更新。
- 使用 `taskStore` 追踪后台拉取任务进度。
- 维护 `activeTab` 状态，控制右侧内容的显示。

### 3.2 页面结构 (`Images.vue`)
- **左侧**：本地镜像资产清单（保持现状，含过滤和清理功能）。
- **右侧**：详情/全观测台。
  - **Header**: 包含选项卡切换和选中镜像后的元数据。
  - **Content Area**:
    - `activeTab === 'pull'`: 镜像仓库面板。包含搜索框、搜索建议列表、后台任务进度。
    - `activeTab === 'layers'`: 选中镜像的层级构建历史。
    - `activeTab === 'inspect'`: 选中镜像的详细 Inspect 信息。

## 4. 修复计划
- 修复 `src/views/Images.vue` 中 `264` 行左右的脚本/模板截断问题。
- 修复 `handleMenuSelect` 函数缺失问题。
- 修复 HTML 标签嵌套错误。

## 5. 验收标准
- 镜像搜索工作正常，且不产生确认弹窗。
- 选中搜索建议后直接触发异步拉取。
- 右侧选项卡顺序正确且切换流畅。
- 页面在各种屏幕尺寸下布局正常（保持 Apple 风格）。
- 文件语法正确，能够成功编译和运行。
